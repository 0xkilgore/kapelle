## Changes made for publication

Files marked **modified** below differ from their source. Every change is a scrub, a portability fix, a stale-test repair or (for the pilot owner ID) a configuration default. No assertion was weakened.

- **Removed from copied trees** (personal data, private infrastructure or internal process): the Registry host runbook, service-manager files, compose and backup/restore scripts, the daily operator-report publisher and its tests (it reads personal logs), the Framework's internal review packets and ops docs with home paths, the cross-repository integration tests that need private sibling checkouts (`agents-graceful-integration`, `verified-result-closed-loop`), the Task Authority's to-do file adapter, and internal evidence/plan documents.
- `console/app/ops/_lib/config.ts`: removed the filesystem topology block (home-directory defaults and private project names). The access-control functions are unchanged.
- `packages/report-registry/README.md`: rewritten. The original described the private deployment.
- `packages/report-registry/src/index.ts`, `src/cli.ts`: dropped exports and the CLI command for the removed operator-report publisher.
- `packages/report-registry/deploy/report-listing-runtime/preimage.json`, `compose-snapshot.mjs`, `deploy/report-snapshot.mjs`: replaced the private Drive ID with the placeholder `00000000-0000-4000-8000-000000000001`, and an absolute host path with a relative `node_modules/` path. The preimage SHA-256 is of the Reactor package file and is unchanged.
- `packages/report-registry/deploy/report-unread-runtime/manifest.json`: replaced the host's absolute target root with `<registry-project-root>`.
- Test fixtures (`promotion.test.ts`, `promotion-request.test.ts`, `report-promotion-request.manager-golden.v2.json`, `task-delegation-client.test.ts`, `claude-builtin-plugins.test.ts`, `claude-provider-auth.test.ts`): replaced a private-network IP, real site names and home-style paths with neutral placeholders. Assertions are unchanged.
- **Cold-review pass.** Code comments and test titles that cited unpublished internal reviews, reviewer names or internal ticket IDs were rewritten to keep only the technical reason. Synthetic fixture identities were renamed to neutral ones (`human:owner`, `research-agent`, `fixture-builder`), except in the hash-pinned recorded capture `tests/fixtures/vetra-generated-review/reviewer-proxy-evidence.json`, which keeps its original bytes (and the author's actor ID) so its pinned SHA-256 still proves what was recorded; a local-model ID and a live-model test flag were made generic.
- `packages/agent-framework/src/service/pilot-observation.ts`: the pilot owner ID is configuration (`KAPELLE_PILOT_OWNER_ID`, default `human:owner`) instead of a hard-coded personal ID. `console/app/ops/_lib/delegationClientCommands.ts`: a UI string says "the owner" instead of a name.
- `packages/report-registry/document-models/report-registry/v1/tests/private-command.test.ts`: the stale fake MCP server now returns the complete drive-snapshot envelope the publisher requires. This file is not in the pinned model inventory, so the deployed model digest is unchanged.
- `packages/task-authority/tests/test-discovery.test.ts`: lists committed tests relative to the package, with a filesystem fallback outside a git checkout. Same assertion.
- Package metadata: added `"license": "AGPL-3.0-only"` to every `package.json` and lockfile root; renamed `@kilgore/task-authority-spike` → `@kapelle/task-authority` and `@kilgore/powerhouse-report-registry` → `@kapelle/report-registry`; removed the dead `taskview:gateway` script.
- `packages/agent-framework/README.md`: replaced the stale opening (it predated the live pilot) and relabeled later sections as stage notes.
- Comments and docs (`publication/README.md`, `dispatch/README.md`, `agent-framework/README.md`, `report-unread-runtime/README.md`, `report-listing-runtime/SNAPSHOT.md`, `legacy-model-publication.test.ts`, `fixtures/private-publication.ts`, `vetra-generated-review/provenance.json`): removed host names, a real site name and links to unpublished documents.

Kept deliberately: the model author name in the generated model specifications (changing it changes the pinned model digest) and the `kilgore/report` and `kilgore/task` document-type identifiers (they are protocol identities in existing documents).
