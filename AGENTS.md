# Agent instructions

This is the single source of instructions for coding agents (Claude Code, Codex, Cursor and others) working in this repository. Tool-specific files, if added, should point here rather than repeat it.

## What this repository is

A curated snapshot of Kapelle: Powerhouse document models for agent work (Task, ReviewIntent, Dispatch, Report, AgentDefinition, AgentInstance), the Framework that enforces approval and one-run execution, the Report publisher and Registry bridge, and a slice of the Next.js console. Start with [README.md](README.md), then [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/CODE-MAP.md](docs/CODE-MAP.md).

## Invariants: do not break these

1. **Reducers are pure.** No clock, network, filesystem or model access in any reducer. Timestamps and actors come in on the action.
2. **Approval binds an exact version and hash.** Never add a path where a model, a chat client or a request body can grant authority, approve, or substitute an actor.
3. **One durable claim before any provider call.** A crash, timeout or lost response is `EXECUTION_UNCERTAIN`. Never add an automatic retry of an uncertain execution.
4. **Identity before response.** A publication's identity is derived before the write. After an ambiguous reply, only look it up; "absent" is not permission to publish again.
5. **Verify, don't trust.** A Dispatch result is recorded only after an independent readback matches identity, provenance and the SHA-256 of the exact bytes. A summary or title match is never proof.
6. **A Report never completes its Task**, and never authorizes the next external effect.
7. **Model compatibility is a gate.** Publishing requires the admitted model inventory and holds the deploy lock through readback.
8. **Fixed failure labels.** Raw error text, tokens, paths and hostnames never reach the UI or an API response.

## Generated code

`document-models/*/v*/gen/` (and `packages/task-authority/generated/task-authority/v1/gen/`) is generated by `@powerhousedao/ph-cli` 6.2.1 (`npm run generate`). Change the specification (`*.json` / `schema.graphql`, or `agent-framework/scripts/author-specs.py`) and regenerate; do not hand-edit `gen/`. Authored reducer logic lives in `v*/src/`.

The Report model's file set is pinned by digest in `packages/report-registry/deploy/report-listing-runtime/model-inventory.json`. Changing any file listed there changes the deployed model digest and must be re-admitted deliberately. Extra test files in the directory that are not in the inventory are not part of the deployed model.

## Hygiene

- Never commit secrets, `.env` files, tokens, private keys, local databases, logs or personal data. Fixtures must be synthetic (`example.invalid`, `synthetic-…`).
- No hostnames, IP addresses or home-directory paths in code, tests or docs. Endpoints are loopback-only and come from configuration.
- Keep `SOURCES.md` accurate when you add or replace files that came from elsewhere. Lifted open-source code needs its license and origin recorded there and in the commit message.
