# Kapelle

Kapelle is an owner-approval-first agent platform. An agent works from an organisation's own files: it proposes work, and it produces drafts that people review. Kapelle records:
- what was approved;
- what ran;
- what came back.

An LLM can propose a change but cannot approve its own permissions. Approving a draft is separate from permission to send or publish it.

## What is in this release (2026-11-02)

This repository is a curated public release of Kapelle's source, not the hosted app. Each release is one commit, generated by a scrub manifest from pinned commits of the private repositories. [SOURCES.md](SOURCES.md) lists them: what each component comes from, what was changed for publication, and which tests are skipped and why. The private history is not published.

| Path | What it is |
|---|---|
| `packages/agent-framework/` | The agent kit, Task delegation and its worker, local / hosted / subscription model adapters, the publication protocol and the Powerhouse document models. Also the organisation runtime (website, newsletter, chat, team tasks, schedules), shown here with an example organisation. New in this release. |
| `console/` | A slice of the owner console: Task delegation, the agent picker and the Report reads. |
| `packages/report-registry/`, `packages/task-authority/` | The Report Registry and Task Authority, unchanged from the 2026-10-14 release. |
| `scripts/report-publication/` | A small report store, unchanged. |

Kapelle began with [Powerhouse document models](https://github.com/powerhouse-inc/powerhouse): typed operations and deterministic reducers for Tasks, approvals, Dispatches and Reports.

## Running the tests

Use Node 24 (this release was checked with 24.18.0). Each package is independent. Installing needs network access; the suites use fixtures, fake providers and local listeners.

```sh
(cd packages/agent-framework && npm ci && npm run typecheck && npm test)
(cd packages/task-authority  && npm ci && npm test)
(cd console                  && npm ci && npm run typecheck && npm test)
(cd packages/report-registry && npm ci && npm test)
```

Results for this release, in a clean clone:

| Package | Typecheck | Tests |
|---|---|---|
| agent-framework | passes | 1,039 passed, 0 failed, 432 skipped |
| task-authority | passes | 120 passed |
| console | passes | 58 passed |
| report-registry | 9 TS5097 errors | 176 passed, 20 failed |

- **agent-framework skips:** they need private infrastructure or an external TypeScript child loader. SOURCES.md lists them.
- **report-registry:** the 20 failures are a dated test fixture that has since expired. The typecheck errors and the failures are both unchanged from the previous release and are listed under Known issues in SOURCES.md.

## Limits

This is source for inspection and testing, not a turnkey deployment. Drafts can omit or alter details and need human review. A matching hash proves byte identity, not factual truth. The documents in `docs/` describe the 2026-10-14 snapshot.
